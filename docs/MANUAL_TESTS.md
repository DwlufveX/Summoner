# v0.1 手动验收步骤

请在测试存档中操作，不在正式殖民地上进行死亡测试。

## 准备

启用 Harmony、Core、Royalty、VEF、VPE 和本 MOD。开发者模式创建新测试地图，给一名殖民者原版灵能连接；在VPE面板增加足够点数，解锁「召唤师」，依次学习三个技能。自动测试入口是 `Tools/Test-Game.ps1`，自测成功标志为日志中的 `ALL TESTS PASSED`。

## 正常循环

1. 学习灵魂契约后先收到「遥远的灵魂呼唤」。加速1–2天后收到「被囚禁的灵狼」，跳转至地图内部营地；确认只有一只候选和3–6名敌对部落守卫，且贴图是深色毛皮、翠绿色灵纹/灵光的四向原创外观。保存再读取，确认候选和守卫没有复制。
2. 守卫仍有战斗力时不能签约。击败、击倒或驱离所有守卫，收到守卫被击退提示。另一殖民者仍不能普通驯服候选；真正召唤师靠近12格施放灵魂契约。狼加入玩家阵营，灵魂禁锢移除，主人健康页显示两天灵魂虚弱。
3. 确认成年灵狼在画面上略大于原版森林狼。确认不需要训练：驯服、顺从和释放自动完成，不会衰减。单独选中狼可以原版征召，并能接受独立移动和近战攻击命令；召唤师无需同时被选中或征召。契约页显示移速+10%、伤害+15%、攻击间隔-10%、承伤-15%；健康页显示「灵魂契约强化」。
4. 点开狼的「灵魂契约」页，检查主人、Lv1、经验、羁绊、进化资格。提供正常肉食或饲料、动物睡眠位置、医疗权限。
5. 让狼受到轻伤并由主人治疗；检查伤口使用原生医疗系统、羁绊增长。加速一天共同生活，确认羁绊只增不减。感染属于概率性原生流程，不能以一次没有感染判断失效。
6. 对敌人使用狼的「猎杀指令」，观察攻击工作与经验。Lv3以上获得短暂加速，重复指令不能无限刷新冲刺。
7. 在主人和狼同地图时施放灵魂呼唤。确认名字、伤口、饥饿及等级不变，只改变位置。把狼送进商队后，呼唤应被禁用，不能凭空得到第二只。
8. 开启灵魂链接并让主人受到外部攻击。30格内狼收到真实伤口；超出30格暂停，关闭后不再分摊。链接可以杀死狼，不用于免费吸收伤害。
9. 通过珍奇商队/轨道珍奇商人购买两种经验品，主人右键使用。检查+100/+300经验，羁绊不变。经验达到1400但羁绊不足75时不能进化。
10. Lv5、羁绊75后收到进化来信。双方清醒且相距12格内，确认进化。狼身份与伤病保持、显示巨牙灵狼；追击加速增强，主人重伤或倒地时出现「至死守护」。

## 死亡与恢复

11. 在测试存档中杀死狼：有效契约立即终止，主人获得七天灵魂创伤和负面心情。呼唤不能复活它。保存读取后仍在恢复期。
12. 加速七天；期间不能新契约，结束后再次进入1–2天感应并生成新的守卫营地。新狼为Lv1、零经验、零羁绊、未进化。确认旧狼的尸体与新狼是不同个体。
13. 在另一份测试存档杀死主人：狼存活、契约强化和征召控制被移除，狼失魂一天，随后恢复野性并尝试离开；被堵住出口或倒地时不会被强制删除。
14. 试验贸易、送礼、繁殖与普通驯服入口。有效契约及候选/失魂阶段应受保护；失魂结束后的野狼可以按普通动物处理。

## 尚需长期实测

完整多人同步；Combat Extended和当前大型整合包；连续多季养成的数值与资源消耗；自然感染、长期医疗、极端环境和地图移除/商队解散；多语言与不同分辨率界面。这些不等同于已通过的最小依赖集成测试。
