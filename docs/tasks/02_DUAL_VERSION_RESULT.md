# 双版本构建与真实游戏存读验证结果

日期：2026-10-14。执行者：Codex。工程版本：0.2.0-dev。

结论：1.6 与 1.7 独立构建、数据回归及完整游戏各两轮存读均通过。当前仍是大型版数据底座，没有可游玩的职业或升级循环。

## 本轮实现

- 1.6 使用 net48/Unity 引用；1.7 使用 net10.0/UnityStubs；对应 Harmony 分别引用。
- 同一源码按版本构建，缓存与输出隔离；LoadFolders.xml 每版只加载一个程序集。
- 绑定地图兽、灵境兽后立即同步组件外键，修复加载前无法反查记录的问题。
- 保存真实游戏测试模块与运行脚本；测试模块不进入发布包。
- 构建、诊断测试、包检查、打包工具支持两版；About.xml 已声明 1.6/1.7。

## 测试环境问题与恢复

最初把测试放在系统临时目录并使用资源目录链接，游戏退出清理影响了链接目标。该安排错误已修复：1.6 测试副本从相同程序集哈希的备份恢复，Steam 1.7 经完整性校验重新下载缺失资源。上述最终验证均在恢复后进行。

工具现在完整复制资源，不使用资源链接，默认运行于 C:\SummonerTests，独立 TEMP/TMP，并拒绝系统临时目录；启动前检查 Core、Shader 或 Mono 资源齐备。未写入正式殖民档。
