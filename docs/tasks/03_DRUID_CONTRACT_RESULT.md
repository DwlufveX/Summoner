# 德鲁伊三兽与契约入门结果

日期：2026-10-14。工程版本：0.3.0-dev。

用户已确认首版每个契约位只出一只主兽，狼/熊/鹰轮换，之后通过更多契约位与上场容量解锁同场。

## 已接入

- 觉醒种子：异种商队、轨道异种商人出售，殖民者吸收一份成为召唤师；重复使用被拒绝。
- 简版地图救援：觉醒后附近显现灵狼牢笼，殖民者实际前往打开；有空位且无未处理灵兽时，约两游戏日后继续熊、鹰。暂未做远征/敌方守卫/财富分档任务。
- 缔约：召唤师实际前往、短暂互动后缔约；首兽固定德鲁伊血脉并成为主兽，后续进入最多三只的备用列表，真实实体转入灵境。
- 编队：主人按钮打开面板；呼唤、召回、设为主兽；当前在场时换兽先撤旧再派新，失败时回退，验证前不移动旧实体。
- 控制：契约兽可征召并通过按钮移动/攻击；不修改其动物/殖民者分类。狼、熊近战，鹰使用 20 格切割风刃。
- 食物/睡眠需求、正常医疗与原版动物搬运训练；没有工作经验结算。
- 存档：保留觉醒/救援进度、身份、编队、灵境持有、伤势/需求/物品；读档后可继续召回和轮换。

## 美术与验证边界

灵狼使用原有原创四向素材。熊/鹰参考来自用户提供的历史交付包，原图烧入了棋盘背景；已用 imagegen 去背景、检查真实 alpha 并保存为过渡单视角 PNG，原稿保留在 ArtSource/Reference。完整四向与统一风格尚未制作。牢笼、风刃暂引用原版图形，不附带原版资源。

当前 HP 使用身体模板 healthScale，未按需求表标定单一总 HP；基础护甲只设置 Lv1。未实现专属主动技能、清洁/医疗成长、经验与三选一、熟练度解锁、突破、灵质、锁血/死亡处置/沉睡治疗/复活、威胁点补丁、完整任务和无契约跟随者规则。UI 只验收按钮生成与业务操作，未完成逐按钮视觉/鼠标实测。跨版本迁档、CE、多人尚未验证。
