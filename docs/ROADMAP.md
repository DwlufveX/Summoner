## 进入大型版前的规则衔接

大型版并非简单往灵狼版追加技能。先对以下差异确定实现与存档迁移方案，再开始扩展核心数据模型：

| 事项 | 当前灵狼版 | 大型版需求 |
|---|---|---|
| 依赖 | Royalty、VPE、VEF、Harmony | MVP 原版可运行，不强制 Royalty / Biotech |
| 实体 | 真实动物狼 | 自定义魂缚契约兽，需求定义 Humanlike 及血脉差异 |
| 契约 | 单一主人、唯一狼 | 血脉槽位、主兽、备用兽、独立上场容量 |
| 成长 | Lv1–5、羁绊、固定进化 | 分阶成长与每级一次三选一，共享成长预算 |
| 死亡 | 永久死亡、七天创伤 | Active / Retreated / Sleeping / Lockout / Dead 状态机 |

下一步应从 Phase 1 的数据模型、保存读档和德鲁伊三兽闭环开始，保留 v0.1.2 基线供回归与旧存档方案比较。依赖、实体和死亡规则变更均须对应需求及验收，不能用旧版行为测试通过替代新版验收。
