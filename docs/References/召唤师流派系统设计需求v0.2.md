# 召唤师流派 Mod —— 系统设计需求 v0.8（Codex 实现用）

> 本文档用于直接交给 Codex（或任意编码 Agent）实现 RimWorld 模组「召唤师流派 / Summoner Class」。
> 取代 v0.7。v0.8 重大变更（回应实现前评审 + 用户补充裁决）：
> - **术语三命名（回应评审 1）**：原混用的 "Tier" 拆为 **体量 `occupySlots` / 阶位 `tier` / 血脉阶 `schoolTier`** 三个明确概念（§2.1）。
> - **数值对照总表（回应评审 2）**：一张表列清每个"阶/等级/经验/点数"叫什么、属于谁、怎么来、解锁什么、是否受上限（§2.3）。
> - **真死亡条件（回应评审 4）**：锁血机制使正常战斗基本杀不死，真死亡仅 3 种明确定义条件（§10）。
> - **软重置公式校正（回应评审 ③）**：`inheritFrac=0.35`（示例 100~200→35~70）、`growthPerLevel=1.5^(tier-1)`（Tier1=1/T2=1.5/T3=2.25）、继承基数**不含**特殊变异、给出**唯一计算顺序+上限范围**、特殊变异**层数上限**（§4.2/§4.3/§4.4）。
> - **召唤师成长漏洞（回应评审 ①）**：`schoolTier` 来自 `schoolXP`（来源列清），系技节点/大招**解锁**与**启用**分离——启用需当前在栏有达阶兽，堵住"练一只→换兽白嫖高阶"（§6.1）。
> - **灵质补完（回应评审 ②）**：老存档靠深钻/长程扫描仪找矿；复活消耗随阶上涨；敌对召唤师事件明确为"推荐额外来源"（§10）。
> - **兽的类型明写（回应评审 5）**：全部为**类人或机械体 Pawn**（§7），双火=狂热 passion 在该节点明这是评审 5 的答案。
> - **沉睡换兽加灵魂界上限（回应评审 ⑤）**：`reserveCap` 防止同时收着所有兽（§15）。
> - 文档自包含，删除"同 v0.3"悬空引用；版本表订正 v0.7→v0.8。

## 0. 一句话定位
小人吸收「觉醒道具」成为召唤师 → 获召唤栏位 → 通过按殖民地财富分档的地图任务救出笼中召唤兽并契约（栏位固定为对应血脉）→ 培养可控英雄兽（技能树/干活/进化）→ 兽升级反哺召唤师 → 隐藏混沌栏复制出黑色影子。英雄兽极难被杀（锁血+退回灵魂界），真死亡需灵质复活。

---

## 1. 核心循环
```
吸收觉醒道具→觉醒召唤师(获栏位)
  → 财富分级地图任务 → 救出召唤兽 → 契约(栏位固定血脉)
  → 共同战斗/工作 → 兽升级(变异3选1 + 间隔技能/工作3选1)
  → 兽升级反哺召唤师3选1
  → 兽满40级→突破(阶位+1, 软重置)
  → 召唤师熟练度达阈值→解锁栏位/学核心技
  → 多栏位后可契约新血脉(开新技能树) 或 深化原血脉
  → (Phase3) 混沌影子 / (Phase4) 融合 / 敌方召唤师
```

## 2. 术语与数值体系（评审问题 1、2 的裁决）

### 2.1 三个独立概念（原 "Tier" 拆成三个命名）
| 概念 | 符号 | 范围 | 含义 | 拥有者 | 变化方式 |
|---|---|---|---|---|---|
| **体量** | `occupySlots` | {1, 2} | 兽占召唤师几个栏 | 每只兽 | 由物种/奇遇进化决定，**固定** |
| **阶位** | `tier` | {1..4} | 该兽突破次数 | 每只兽 | 满 40 级自主突破 +1 |
| **血脉阶** | `schoolTier` | {1..4} | 召唤师对该血脉的造诣 | 召唤师（每个血脉一份） | 由 `schoolXP` 阈值提升 |

- **不再循环定义**：总可上场栏 `maxSlots` 由「双魂仪式 / 熟练度阈值」**单独**增长，与 `occupySlots`、`tier` 均无关。
- 满 40 级可**自主突破**（不要求拿到第二只兽或 2 栏兽）→ `tier+1`，`tierLevel→1`，经验基数 `×1.6^(tier-1)`；多余经验进"突破进度池"，不浪费、不卡死。

### 2.2 栏位（Slot）模型
- 召唤师有 `slots: List<Slot>`，`maxSlots` 初始 1。
- 契约 `occupySlots=1` 兽占 1 槽；`occupySlots=2` 兽占 2 槽（需 `maxSlots≥2`）。
- 同一时刻 Active（场上）兽占用的 `occupySlots` 之和 ≤ `maxSlots`。沉睡/在灵魂界 reserve 的兽不占实时上场（但仍占"契约槽"，见 §3）。

### 2.3 数值 → 拥有者 → 来源 → 用途 → 上限 总表（评审 2 的"一张表"）
| 名称 | 符号 | 拥有者 | 范围 | 来源 | 解锁/用途 | 是否受上限 |
|---|---|---|---|---|---|---|
| **体量** | `occupySlots` | 每只兽 | 1/2 | 物种/进化定 | 占几栏、反哺频率（1栏每4级/2栏每2级触发召唤师3选1） | 固定 |
| **阶位** | `tier` | 每只兽 | 1..4 | 满40级突破 | 基数↑/每级增长↑/技能强度↑/血脉被动↑；并作为该兽系技**启用**门槛 | 普通属性受硬上限 |
| **阶内等级** | `tierLevel` | 每只兽 | 1..40 | 杀敌+日常 | 每级→变异3选1；每4级→技能/工作3选1；满40→可突破 | 固定 40 封顶 |
| **召唤师熟练度** | `summonXP` | 召唤师 | 累计 | 用召唤技/战斗/契约 | 达阈值→`maxSlots`+1、学核心绑定技 | 软上限(阈值) |
| **血脉阶** | `schoolTier` | 召唤师/每血脉 | 1..4 | `schoolXP` 达阈值 | 系技 greater 节点(≥2)**解锁**、大招(≥3)**解锁** | 受 `schoolXP` 阈值 |
| **血脉经验** | `schoolXP` | 召唤师/每血脉 | 累计 | 该血脉兽升级/击杀/协同战斗/契约 | 提升 `schoolTier` | 阈值 |
| **灵质** | `ectoplasm` | 物资 | 数量 | 采矿/击杀敌方召唤师/任务 | 复活(随阶↑)、突破材料 | 可囤积 |

> 明确删除"技能点"货币：所有"学技能"都走 3选1 队列（§5），不再另设点数。
> 注意 `schoolTier`（解锁门槛）与"该兽 tier≥N 在栏"（启用门槛）是两个不同的门，详见 §6.1。

## 3. 召唤师与觉醒
- 小人使用「觉醒道具」（消耗品，每件对应一名小人；多人可各用一件成为召唤师，用于分摊风险 / 多召唤师平衡）→ 获得 `SummonerComp` + 初始 `maxSlots=1`（Adaptive 栏）。
- 觉醒后触发**最初的契约**任务（低财富守卫，见 §15）。
- 觉醒道具**可重复获取但每件单次消耗**：一名小人只能觉醒一次；多件→多召唤师（设计内允许，用于 §16.2 平衡）。

## 4. 成长：等级 / 突破 / 软重置（评审问题 3 的裁决）

### 4.1 升级经验
`tierLevel` 经验来自：兽击杀敌人、兽完成日常工作、主人用召唤技。单级经验曲线轻微递增。
- **经验节奏（待实测，初值）**：约 1~2 游戏日/级（活跃战斗+工作），满 40 级 ≈ 一个季节。
- **随阶变难**：突破后经验需求曲线更陡（`单级经验 × 1.6^(tier-1)`，且高阶击杀/工作的单位经验衰减），让突破成为有成就感的长线目标，而非无脑刷。

### 4.2 突破（软重置，按用户公式，已校正口径）
满 40 → 玩家触发突破。记突破前该兽**普通属性**有效值 `prevNormal = normalStats(tier, 40)`（**不含**特殊变异乘区）。
- `tierLevel → 1`，`tier + 1`。
- **新阶基础（普通属性部分）**：`tierBaseNew = prevNormal × inheritFrac`，`inheritFrac = 0.35`。
  - 用户示例：Tier1 Lv40 普通属性 ≈ 100~200 → Tier2 Lv1 ≈ 35~70。**文档内一律写 0.35，不再写"1/35"**，避免实现者照字面写错。
- **特殊变异不计入继承基数**：体型/多肢/部件优化等永久保留，作乘区在 §4.4 计算顺序里单独应用（不乘在 `prevNormal` 里），**避免重复计算**。
- **普通属性清零重算**：阶内每级线性累加的普通属性（攻/速/甲/普血）归零；但因已含在 35% 继承中净失有限，新阶可重洗。
- **每级增长变大**：`growthPerLevel(tier) = growthPerLevel(1) × 1.5^(tier-1)`。
  - 统一公式后：Tier1 = 1.0，Tier2 = 1.5，Tier3 = 2.25，Tier4 = 3.375。（文档内一律写 `1.5^(tier-1)`，不再写"×1.5^tier"。）
- **硬上限随阶上调**：普通属性单属性硬上限 = `基线 × (1 + 2×tier)`（tier1 +200% … tier4 +800%）。
- **技能**：已解锁技能**不删除**，技能等级降回该阶 1 级，技能"强度档"随 `tier` 上涨。
- **示例**：Tier1 Lv1 基础=1，Tier1 Lv40≈100~200（含普通变异）；Tier2 Lv1≈35~70（×特殊变异乘区后更高），Tier2 每级 +1.5 → Tier2 Lv40 轻松超过 Tier1 满级。

### 4.3 变异属性分类与递减
每级变异 3选1 选项：
- **普通变异（绝对，软重置时归零重算，但已计入 inheritFrac）**：攻击力 / 攻击间隔(攻速) / 护甲 / 普通生命值。
- **特殊变异（永久乘区，跨阶保留，有层数上限）**：
  - 体型增大：HP/伤害按比例放大，**≤ 3 层**。
  - 多手臂：额外攻击段/格挡，**≤ 2 层**。
  - 身体部件优化（再生腺体/护盾器官等）：**≤ 2 层**。
- **同属性递减**：普通变异第 n 次选同一属性，收益 = `baseGain × 0.85^(n-1)`。
- **硬上限随阶上调**（见 §4.2）：普通属性单属性总加成 ≤ `基线 × (1 + 2×tier)`。
- 效果：永久成长感 + 爽点叠加都在，但"绝对值"受软重置、递减、层数上限约束。

### 4.4 最终属性计算顺序（明确叠加，避免重复/无限爆）
```
最终属性 = [ 基础(tierBaseNew)
            + 阶内累加( 等级 × growthPerLevel(tier) + 普通变异 )
              先经 "同属性递减 0.85^n" ]
          → 截断到 硬上限 = 基线 × (1 + 2×tier)        ← 仅这一段受硬上限约束
          × 特殊变异乘区( 体型/多肢/部件，各受 §4.3 层数上限 )
          × (1 + 血脉被动加成)                          ← 不受普通硬上限，但被动自身有上限(§14)
          × (1 + 仿生反馈加成)                          ← 不受普通硬上限，但仿生同属性递减(§12)
```
- **受硬上限约束的项**：仅"基础 + 普通属性累加"这一段。
- **不受普通硬上限约束（但各自有递减/层数上限）**：特殊变异乘区、血脉被动、仿生反馈。
- 这样后期不会"9倍×体型×仿生"无限爆：普通属性被上限夹住，乘区项各自有上限，且仿生按你要求不封顶但有同属性递减防爆。

## 5. 3 选 1 奖励系统（评审问题 9：改为队列）
- **不再即时弹窗**。升级只把奖励压入 `pendingRewards` 队列；玩家空闲时点召唤师 gizmo 的「未决奖励」一次性逐个选择（§17）。避免多兽同升疯狂弹窗。
- 队列两类：
  - **A 变异**（每级必给）：§4.3 选项 3选1（永久、递减、层数上限）。
  - **B 技能/工作**（每 4 级）：技能池随机 3（新学/精进/变异）+ 培养型工作 3选1。
- 占 1 栏兽在高层 tier 时，池 B 中 "greater" 节点不可见 → 实现"技能更少"。

## 6. 召唤师反哺与血脉阶（回应评审 ① 漏洞）
- 兽被动反哺主人（扩展灵魂共鸣）。
- 频率按体量平衡：**1 栏兽每升 4 级** / **2 栏兽每升 2 级** → 触发召唤师一次 3选1。两只 1 栏 ≈ 一只 2 栏（集中 vs 多样/容错）。
- 召唤师奖励池：召唤师属性 / 核心绑定技升级 / 反哺强度。

### 6.1 血脉阶的"解锁"与"启用"分离（堵刷阶漏洞）
- `schoolXP` 来源（明确）：**该血脉兽每次 `tierLevel`+1、该血脉兽击杀敌人、与兽协同战斗、契约该血脉兽事件** 各给一定 `schoolXP`；达阈值 → `schoolTier+1`（召唤师持久成长，体现"人跟着兽一起长"）。
- **解锁门槛**：系技 greater 节点需 `schoolTier≥2`、大招需 `schoolTier≥3`（仅 `schoolXP` 决定，持久）。
- **启用门槛（新增，堵漏洞）**：节点/大招实际可释放，**还要求当前在栏中存在至少一只该血脉兽且其 `tier≥对应阶`**。
- **效果**：把一只兽练上去拿到 `schoolTier` 后沉睡换兽 → 高阶技能保持"已解锁"但**灰显不可用**，直至你再培养出一只达该阶的该血脉兽。这是**有意设计**：召唤师知识可积累，但战力需当前阵容支撑，防止"练一只→换阵容白嫖高阶"。

## 7. 召唤兽类型与需求（评审问题 5 的地基裁决 —— 明写）
> **关键裁定**：全部召唤兽为 **humanlike Pawn 或机械体 Pawn**（类人/机械，非普通动物）。这回答了评审第 5 点——只有类人/机械体才能拥有技能等级、兴趣火焰(passion)、干活、穿装备(影子)、受伤致残、接受手术。"双火"=狂热 passion（§13）正是建立在此前提上，兽因此天然是类人/机械体，不再另作解释。

按血脉区分：

| 血脉 | 类型 | 吃饭 | 睡觉 | 心情 | 可穿装备 | 仿生 | 备注 |
|---|---|---|---|---|---|---|---|
| 德鲁伊(狼/熊/鹰) | humanlike | ✓ | ✓ | 羁绊 | ✗ | ✗ | 力量来自本体 |
| 亡灵 | 机械/构造 | ✗ | ✗ | ✗ | ✗ | ✗ | 构造态 |
| 元素 | 构造 | ✗ | ✗ | ✗ | ✗ | ✗ | 构造态 |
| 机械 | 机械 | ✗ | ✗ | ✗ | ✗ | ✗ | 需供能(Biotech 带宽被动) |
| 虫族 | humanlike/有机 | ✓ | ✗ | ✗ | ✗ | ✗ | 有机 |
| 混沌影子 | humanlike(克隆本体) | 同本体 | 同本体 | 同本体 | ✓ | ✓ | 人类小人、无社交 |

- **非影子兽不可穿装备/武器**：战力来自属性+技能，平衡可控。
- **影子**=本体克隆的人类小人，可穿装备、可用灵能/他职。

## 10. 锁血 / 退回 / 真死亡 / 灵质（评审问题 4 的裁决）
- **锁血退回**：兽 HP < `lockHpPct`(≈15%) 且处于战斗危险 → 自动包扎全部伤口并退回灵魂界；CD 内不可再触发。期间可召出做手术。
  → 因此**正常战斗几乎杀不死英雄兽**：只要锁血触发，它已脱离战场、不可被继续攻击致死。
- **真死亡仅在以下 3 种情况（明确定义）**：
  (a) 锁血退回**冷却中**（刚退回不久）再受致命伤，或在灵魂界内被「反召唤·裂隙入侵」直接击杀；或
  (b) 被「反召唤·断魂」技能**无视锁血**击杀（高阶反召唤单位专属）；或
  (c) （后期）灵魂界被「裂隙入侵」攻破，界内兽批量真死。
  - 普通袭击/普通武器**无法**造成真死亡（锁血兜底）。灵质资源因此有意义。
- **复活**：消耗灵质，**复活消耗随阶上涨** `reviveCost(tier) = base × 1.6^(tier-1)`（tier 越高越贵，防后期囤积白复活）+ 召唤师 debuff + 冷却。无灵质则永久失去，直至获得。
- **灵质（Ectoplasm）来源（用户裁定：矿物 + 敌对召唤师）**：
  (1) **矿物（主来源，稳定）**：灵质是地图上一类**可采矿物**（灵质矿脉，按原版采矿方式开采，稀有度高于铂金/铀）。
      - **老存档兼容**：中途加 mod 时，已生成地图用**深钻机(Deep Drill) / 长程矿物扫描仪(Long-Range Mineral Scanner)** 仍可在地下/远图探测到灵质矿（按稀有矿生成规则）。
  (2) **击杀敌方召唤师（推荐额外来源）**：敌方召唤师事件（§16.4）击杀其召唤兽有概率掉落灵质。该事件为**推荐/应做**而**非必需**——灵质主来源是矿物，事件只是补充，避免"事件可选→灵质断供"。
  (3) 任务奖励（少量）。
  > 取代原"凝聚仪式"设定——改为更贴合原版经济循环的开采+击杀掉落。

## 11. 混沌影子（评审问题 10：移出 MVP → Phase 3）
- 隐藏稀有栏：将主人投影为黑色影子契约兽（人类小人），有进化、每升 1 级触发召唤师 3选1。
- 基础技「互换位置」：CD=1 天（60000 ticks）、支持跨地图（异图时传送交换）。
- 技能回声：主人技能按 `skillEchoRatio≈0.65` 减弱同步；主人技能变强影子同步变强。
- 可学他职（机械师/灵能/医疗等），无社交。
- 视觉：黑色半透明描边，区别于普通英雄兽。
- **Phase 3 再做**：实现成本与平衡风险最高。

## 12. 仿生反馈（评审问题 8 的裁决）
- 召唤师仿生**净增益**按 `k_fb≈0.4`（影子 0.25）平乘给每只兽；**单向**（兽→主人不回授，防左脚踩右脚）。
- **属性映射表**（仿生→兽属性）：操作→工速；视力→远程精度/命中；移动→移速；代谢→恢复；神经→技能冷却。
- **不封顶**（按用户实测要求），但**同属性多件递减**（每件后续收益 ×0.8），列为调参风险项。仿生位于 §4.4 计算顺序末段乘区，受自身递减约束，不在普通硬上限内。

## 13. 工作类型（用户裁定：初始等级 8 + 狂热 passion）

- **初始等级 = 8**。
- **"双火" = 游戏内 passion「狂热」(Major，双火焰图标)**：血脉专属工作类型初始即为**狂热 passion**，学习速度 ×150%（`passion=Major` 固有倍率）。即召唤兽一契约就有高起点+高速学习，符合"双火"。（这同时确认兽是类人/机械体，见 §7。）
- 培养型：到等级可 3选1 开发额外工作类型（可跨血脉），新开发工作默认 Minor passion（除非特殊事件给狂热）。

## 15. 任务 / 事件（财富分级守卫，自包含）
觉醒后按殖民地财富分档触发**救出召唤兽**任务，笼中解救后：有空栏→契约请求（栏位固定血脉+习得系技/哨塔/临时召唤）；无栏→以动物身份加入。
- **沉睡换兽（轮换机制，纯冷却 + 灵魂界上限）**：已契约兽可「沉睡」腾出栏位去契约其他血脉兽。
  - 代价为 `swapCd`（≈3 游戏日）冷却，期间该栏不可契约新兽/不可召回原兽；CD 结束原兽可再召或换契约。无 HeDiff、无灵质。
  - **灵魂界存放上限 `reserveCap`（回应评审 ⑤）**：`reserveCap = max(3, maxSlots)`（初值建议 3）。在 reserve 中的兽数量 ≥ `reserveCap` 时**不可再沉睡**（须先永久释放一只或等其被召回）。这防止"所有兽都收着、按局势每 3 天换一只 = 同时拥有所有兽"。
- **低财富**：弱小部落发现异常灵兽，想抓去卖给帝国（Royalty，无 DLC 降级为普通商队）。守卫种族按血脉映射：人族→亡灵、野兽→德鲁伊、元素→元素、机械→机械、虫族→虫族。
- **中财富**：带召唤师的崛起部落，欲强行契约。
- **高财富**：失控灵兽被敌对武装势力逮捕。
- 契约成功 → 栏位固定该血脉，习得：召唤/召回/复活/对应流派临时召唤物/永久不可移动哨塔；兽习得「退回召唤界」（与主人召回共享 CD）。

## 16. 平衡方案（评审问题 6、7 的裁决）
### 16.1 必须做
1. **战力计入威胁点**：召唤师+兽有效战力折算进 Storyteller 威胁点 → 越强袭击越多（按**全殖民地**有效战力，非仅召唤师）。
2. **栏位上限**限制同时上场兽数。
3. **属性递减**：变异同属性递减 + 硬上限（§4.3）+ 特殊变异层数上限（§4.3）。
### 16.2 应该做
4. **反召唤 / 精英单位**：高阶袭击注入能压制召回、伤灵魂界、集火主人的单位 → 破"技能+拉扯"循环（direct counterplay）。
5. **多召唤师**：觉醒道具可多人用，缓解单点失效。
6. **光环共享**：野兽光环让普通殖民者受益，避免只揍脆小人。
### 16.3 相对指标（取代"20~30/50+"）
- *Tier1 满级兽 ≈ 3~4 名基准殖民者*；*加技能拉扯 ≈ 6~8*。先对标原版，Combat Extended 等另议。
### 16.4 敌方召唤师
仅作**后期偶发高威胁事件**（敌方召 1~2 兽），非常规袭击配置；产出灵质为**推荐额外来源**（§10）。
### 16.5 经验基数
`tierXpBase(tier) = base × 1.6^(tier-1)`。
