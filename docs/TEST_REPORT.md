## 本轮反馈的实现结果

| 反馈 | 实现 |
|---|---|
| 灵狼模型需要绿光辨识度 | 替换为原创四方向动物贴图：深色狼身、翠绿眼睛、灵纹与克制的绿色灵光；不含第三方美术 |
| 签约后无法控制 | 契约狼现在使用原版征召按钮，并接受直接移动和攻击命令；旧存档中的有效契约会在周期更新时自动补上控制能力 |
| 不应要求训练顺从 | 签约时自动完成驯服、顺从与释放，并锁定主人；玩家无需训练或维护顺从度 |
| 契约应增强属性 | 新增立即生效的契约强化：移速+10%、近战伤害+15%、攻击间隔-10%、承伤-15%；断契时移除 |
| 不应直接出现在门口 | 学会契约后先感应1–2天，再在地图内部生成临时营地；灵狼被3–6名敌对部落成员守卫，必须击败、击倒或驱离有战斗力的守卫后才能营救签约 |
| 灵狼应比原版狼更大 | 成年绘制尺寸由1.4调整为2.2，物理体型由0.85调整为1.0；原版森林狼约为1.95和0.85 |

事件目前是当前地图中的临时营地，不是独立世界地图任务。候选被灵魂禁锢限制在营地附近；事件超时或召唤师失效后，候选和残存守卫会尝试离开地图。
