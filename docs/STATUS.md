## 待实现

数据层支持成长与奖励的存储，但当前不会主动升级、发成长选择、反哺或解锁容量。灵境能保存、呼唤与召回真实实体；普通待命暂停实体活动，未实现沉睡治疗或复活。

仍待实现：完整远征/守卫/财富分档救援、无契约跟随者规则、专属技能、清洁/医疗与自定义工作等级、经验结算、成长选择、主人反哺、四阶突破、容量/多槽解锁、灵质经济、锁血/死亡处置/沉睡治疗/复活、威胁点补丁、完整 UI 和熊鹰四向美术。

当前 Mod 有 11 个具名、按类型去重的定义。初始一槽一容量；每槽一主三备。同槽备用兽只能替换主兽，不能直接同时出场。HP 暂用身体模板的 healthScale 表达，尚未标定为单一总 HP；阶内护甲增长尚未实现。
